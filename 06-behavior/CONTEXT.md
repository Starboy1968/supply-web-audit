# Stage 6: Behavior
Job: Read what players do, from records only.

## Inputs
Working (this run):
- `03-link-ledger/output/ledger.csv`
- Client records over at least two periods
Reference (every run):
- `_shared/behavior-rules.md`
- `_shared/payoffs-and-drivers.md`

## Process
1. For each key player, pick two agreeing indicators across two periods.
2. Write the pattern observed. Never a trait.
3. Write the best alternative explanation.
4. Note which payoff the pattern serves.

## Outputs
- `06-behavior/output/behavior.md`

## Human check
Owner reads the alternative explanations and flags any unfair read.
