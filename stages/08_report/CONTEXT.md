# 08_report: report and set triggers

One job: write findings with cause labels and the triggers that reopen the audit.

## Inputs
- Working (this run): ../01_scope/output/scope.md through ../07_test-moves/output/tests.md
- Reference (every run): ../../_shared/evidence-labels.md
- Reference (every run): ../../_templates/finding.md

Do NOT load: raw client records.

## Process
1. Write findings from the template. Each carries a cause label and an evidence label.
2. List open gaps.
3. Set re-audit triggers (lender change, new hub, late-payment pattern, AI autonomy change).
4. Plain language, executive format, under three pages.

## Outputs
- report.md → output/

## Human check
Owner signs off before anyone outside reads it. Edit in place.
