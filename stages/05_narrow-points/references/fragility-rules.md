# Fragility rules
- Common-dependency check: a second supplier on the same bank, port, cloud, or owner is not redundancy.
- Hub: many links run through one player. Bridge: the only link between two clusters. Keystone: small player, large effect.
- Loop: feedback that amplifies. Threshold: past this point behavior flips. Delay: the shock arrives later than the cause.
- Constraint search: find the single thing that limits the whole web.
- Hub threshold: case by case (open question).
