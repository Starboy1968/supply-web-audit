# Behavior scoring rules
1. Score only from observable records (payment timing, terms changes, contract moves, filings).
2. Two agreeing indicators across two periods before any score.
3. Write the best alternative explanation beside every score.
4. Write "pattern observed", never a trait.
5. Score firms only until legal review for named individuals is done (see client profile).
