# 06_behavior: read behavior from records

One job: describe what key players do, from observable records only.

## Inputs
- Working (this run): ../03_link-ledger/output/ledger.csv
- Working (this run): client records covering at least two periods
- Reference (every run): references/behavior-rules.md
- Reference (every run): ../../_shared/payoffs-and-drivers.md
- Reference (every run): ../../_templates/finding.md

Do NOT load: money-map, tests, or report material.

## Process
1. For each key player, pick two agreeing indicators across two periods.
2. Write "pattern observed" (never a trait) and the best alternative explanation.
3. Note which payoff the pattern serves.

## Outputs
- behavior.md → output/

## Human check
Read each alternative explanation and flag any unfair read. Edit in place.
